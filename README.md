# La Lupe · Cocina mexicana

El sabor de México para compartir en Chía, Cundinamarca. Una mesa llena de color, platos para disfrutar juntos y antojos para cada encuentro.

Fajitas, tacos, taquizas, entradas para compartir, sopas, carnes y postres. Entre nuestras especialidades están la Taquiza, la Carne a la tampiqueña, los Nachos grandes y el Combo «mero mero».
